# Product Pulse Synthetic Data

All data in this capstone is synthetic and generated programmatically; it does not represent real customer/company records.

- Period: January–December 2025 order history
- Fixed random seed: 42
- Products: 40 across 6 categories
- Customers: 500
- Orders: 5,010
- Review/ticket text is generated from controlled issue profiles.
- Eight products have deliberately seeded risk patterns so evaluation and demos are reproducible.

Rebuild all core data with `python scripts/generate_data.py`.
