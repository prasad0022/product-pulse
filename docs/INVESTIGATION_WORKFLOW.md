# Product Pulse — Investigation Workflow

## Current MVP
1. Select a product from the risk ranking.
2. Read current product risk signals.
3. Pull historical product trend.
4. Summarize support-ticket signals.
5. Retrieve product knowledge/RCA documents.
6. Produce evidence-backed root-cause candidates and recommended actions.

## Next integration
The deterministic investigation service will become the tool layer for the LLM/agent. The LLM will synthesize the tool outputs into a business-facing answer with source citations.
